# The World in One Picture — 23 Nov 2026

This repository is an entry to the make.fun bounty at https://make.fun/bounty/news-image-20261123 whose program copies a one-page newspaper image summing up the world news of Monday 23 November 2026 (the COP31 climate talks collapsing with no deal, the Democrats clinching a 258-seat House majority, two wounded as Iran strikes US bases in Bahrain, and Liverpool routing Manchester United 4-0) to the output directory.

## Run it

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
